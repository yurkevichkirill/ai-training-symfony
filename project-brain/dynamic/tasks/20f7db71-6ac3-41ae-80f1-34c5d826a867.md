THREE REAL DEFECTS CAUGHT BY TESTS: (1) WebTestCase reboots the kernel per request, giving each request a fresh Doctrine connection that cannot see uncommitted fixture rows — every sign-in failed as 'unknown account' AND the four failure assertions still passed because all causes had collapsed into one; fixed with $client->disableReboot(), which EVERY data-seeding functional test must do. (2) The timing test caught a real 40x gap (unknown email 5.4ms vs wrong password 218ms) — root cause was UserFactory hashing at full production strength while the app's when@test hasher is cheap (time_cost 3, memory_cost 10), so real verification cost 40x what padding could; fixed by aligning the factory, comments on both sides. Test-only artifact; production already matched. (3) default_target_path: app_home needed Task 20's route.
